# Card faces

Standard English-pattern card faces by Adrian Kennard (https://www.me.uk/cards/),
released into the public domain under CC0 1.0, via the `@letele/playing-cards` package
(also CC0). Rendered to plain SVG files; the corner rank and suit were enlarged
(rank 32→46, suit 27→36 units) so they stay readable in a fanned hand, and the viewBox was widened
(240×336 → 256×360, same proportions) to leave a margin around the artwork.

Files are named `<rank><suit>.svg`: rank `a k q j 10 9 8 7`, suit `c d h s`.
The card back is drawn in CSS (see `Card.css`).
